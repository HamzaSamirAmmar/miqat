# Adhan recordings

Bundled adhan recordings sourced from the [adhan-mp3 collection]
(https://github.com/Kiwifu/adhan-mp3), which aggregates freely distributed
recordings of the adhan (Islamic call to prayer).

| File | Recording |
|---|---|
| `makkah-fajr.mp3` | Adhan al-Fajr — Al-Haram al-Makki (Makkah) |
| `madinah-fajr.mp3` | Adhan al-Fajr — Al-Haram al-Madani (Madinah) |
| `makkah.mp3` | Ali ibn Ahmad Mala — Al-Haram al-Makki (Makkah) |
| `madinah.mp3` | Adhan — Al-Haram al-Madani (Madinah) |
| `aqsa.mp3` | Adhan — Al-Masjid al-Aqsa (Jerusalem) |
| `alafasy.mp3` | Mishary Rashid Alafasy (Kuwait) |

Attribution to the reciters and the source collection is appreciated if these
files are redistributed. Verify the collection's redistribution terms before
shipping them in your own product.
