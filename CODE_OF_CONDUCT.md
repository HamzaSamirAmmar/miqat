# Code of Conduct

## Our pledge

Everyone participating in this project — issues, PRs, discussions — is expected
to be respectful and constructive. Harassment, personal attacks, or disruptive
behavior will not be tolerated.

## Standards

**Examples of encouraged behavior:**

- Kind, patient, assumption-free communication
- Accepting constructive criticism gracefully
- Focusing on what's best for the project

**Examples of unacceptable behavior:**

- Harassment, insulting or derogatory comments, personal attacks
- Publishing others' private information without consent
- Other conduct reasonably considered inappropriate in a professional setting

## Enforcement

Violations can be reported by opening a private GitHub security advisory or
contacting the maintainer directly. Maintainers may remove, edit, or reject
contributions that violate this code of conduct.
